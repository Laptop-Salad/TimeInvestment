# User Stories

To ensure the software flowed in a way that was natural to a wide range of users,
several user stories and flow diagrams were developed. All users described here
are fictional.

## The Student

As an academic I want to be able to track the different ways I study material
to be able to track has the best result.

## The Hobbyist

As a hobbyist I want to see the work I have put into an activity as that 
motivates me to do more.
